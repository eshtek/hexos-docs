# About HexOS

HexOS is software for running a home server on hardware you own. You can keep photos, videos, documents, and backups on that server. You can also run apps for media, home automation, games, and other services.

A server that shares files over a network is often called a NAS, short for network-attached storage. HexOS combines those storage functions with tools for setting up and managing your server.

## Manage your server with the Command Deck

The Command Deck is the HexOS interface you open in a web browser. It works on computers, tablets, and phones. You can manage storage, install apps, check activity, and review alerts from one place.

During setup, HexOS guides you through choosing a storage layout. After setup, you can manage files and decide which users can access your shared folders.

## What you can do with HexOS

- [**Storage**](/features/storage) lets you organize drives into pools and check their status.
- [**Folders**](/features/folders) lets you share files with other computers. Bring Over copies files from supported network, external-drive, and cloud sources to your server.
- [**File browser**](/features/file-browser) lets you upload, download, and organize files in your browser.
- [**Apps**](/features/apps) provides a catalog of services you can run on your server, including photo libraries and media servers.
- [**Virtual Machines**](/features/vms) lets you run operating systems such as Windows or Linux on your server.
- [**Buddy Backups**](/features/backups) lets you keep encrypted folder backups on a friend's HexOS server or another server you own.
- [**Health and capabilities**](/features/health-and-capabilities) provides diagnostics and an option to share hardware information for Hardware Advisor recommendations.

Virtual Machines and Buddy Backups are individual features in beta. Their guides explain the current limits.

## Choose your hardware

You can reuse a compatible computer, build your own server, or choose compatible prebuilt hardware. HexOS supports Intel and AMD systems that meet its requirements.

Plan for a dedicated boot SSD and separate drives for your files. Apps and Virtual Machines can need more resources than basic file storage. Check the [system requirements](/getting-started/overview#system-requirements) before buying parts or installing HexOS.

## Built on TrueNAS

HexOS is built on TrueNAS, which provides the underlying storage platform. Our partnership with TrueNAS lets us focus on making server management easier to use. The TrueNAS interface remains available when you need its additional controls.
