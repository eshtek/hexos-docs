# July 9, 2026 - New App Curations (Rackula, Warracker & Wiki.js)

## New Curations

With today's batch of apps we have more than doubled our curations.

[Rackula](https://github.com/RackulaLives/Rackula) - Rackula is a Drag-and-drop rack layout designer.
[Warracker](https://github.com/sassanix/warracker) - Warracker is a warranty tracker to monitor expirations, store receipts, files.
[Wiki.js](https://js.wiki) -  Wiki.js is an open source Wiki software

## Curation Updates

[Snapotter](https://github.com/snapotter-hq/SnapOtter/releases/tag/v2.0.0) has release Version 2.0 which expands its feature set beyond just images.

To update to 2.0 you will need to uninstall the app and reinstall it.
> Be sure to check the box `Also remove application settings and config files`
