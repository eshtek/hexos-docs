# October 13, 2026 - Private folders stay private, smarter Custom VMs, and more

Here is a summary of changes shipped since our [last update](/release-notes/command-deck/2026-10-09).

## Storage

- In some cases, a pool drive that stayed degraded could be reported again every few minutes, which brought back notices you had dismissed and could escalate to a replace-the-drive recommendation. HexOS now reports it once, and only again if the drive recovers and fails a second time.

## Folders

- **Private folders stay out of sight.** When someone browses your server in Finder or File Explorer, they now see only the folders they are allowed to open. Guests no longer see the names of your private folders. Requires TrueNAS 25.10 or later.  Your existing folders should be updated automatically. If you still see shares that are inaccessible (eg. MacOS) you can apply a one-time benign edit to the folder in the Deck and that will force your Finder or File Explorer to refresh the listing.

## Virtual Machines

- **Custom VMs start their own installer.** Many installers wait for a key press before they boot. HexOS now reads your installation media and presses the key for you only when the installer asks for it, so a Custom VM goes straight to installing.
- **Windows recognized automatically.** A Custom VM created from a Windows installer is set up as Windows even if you did not pick an icon. Other Custom VMs without an icon are set up as a general guest.
- **Home Assistant opens on the right port.** **Launch** now opens Home Assistant on the port it answers on, for new and older installs alike.
- In some cases, a VM could not be removed from a server with virtualization turned off in its BIOS. Removal now works.


## Graphics card sharing

- **Safer switching for AMD cards.** When you move an AMD graphics card away from **VMs**, your apps get it back the next time the server restarts, and the **Graphics cards** settings say so. Some AMD cards can freeze a server when handed back while it is running. Intel and NVIDIA cards still switch right away.
- **Your apps keep their card.** A graphics card that an earlier install reserved for VMs now starts as **Automatic**, so apps already using it keep running.
- In some cases, an app using an Intel or AMD card could fail to start while a VM had the server's last card. It now waits and starts again once the card is back.

## Buddy Backups

- **Backups from your server's own Command Deck.** The **Backups** page now works when you open Command Deck directly from your server.
- Backups can now be stored on a pool whose name contains a space.
- In some cases, a backup could stall for up to an hour after TrueNAS restarted its services. It now continues on its next run.

## Design and reliability

- **Each browser tab remembers its server.** If you manage more than one server, each tab now stays on the server you picked in it, even after a reload.
- **Easier to read.** Small purple labels, links, and tags are now clear in both light and dark themes.
- In some cases, a long script in **Install with custom script** was cut off. The editor now scrolls.
- In some cases, an action sent to your server during a brief connection drop could run twice. Each action now runs once.

**NOTE:** All of these updates are applied automatically to your Command Deck. You may need to clear your cache. Help with clearing your cache is available [here](/troubleshooting/browser-cache).
