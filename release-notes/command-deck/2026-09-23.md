# September 23, 2026 - App fixes and beta feature updates

Here is a summary of changes shipped since our [last update](/release-notes/command-deck/2026-09-18).

## Apps

- In some cases, an app update could reset GPU preferences. GPU selections are now preserved through updates.
- In some cases, reading an app's status could redirect Docker to a different storage pool. Docker's pool is no longer changed during routine status checks.

---

## Beta feature updates

The following updates apply to features currently in beta. If you are not enrolled in a beta program, these sections do not affect your server. Both Virtual Machines and Buddy Backup are rolling out gradually. Want to try them? [Sign up for the beta.](https://docs.google.com/forms/d/e/1FAIpQLSfDWcQzKR6wnGHV8lKNQhZH8DmSAuXIIXsgmK4BpswLJg36LA/viewform)

### Virtual Machines

Virtual Machines let you run Windows, Linux or an appliance like Home Assistant directly on your server, with a hands-off installation that sets up your account and installs the apps you choose before you ever sign in. [Read the full announcement.](/blog/2026-09-23)

- **Use the VM console from your phone.** The console now supports touch input, a soft keyboard, pinch-to-zoom up to 4x, and a key strip with Esc, Tab, arrows, function keys and sticky modifiers. A trackpad mode is available for targets smaller than a fingertip. The console adapts its layout to phone-width screens with a collapsible menu.
- **Power controls in the console.** A Power menu in the console toolbar lets you shut down, restart or force power off without leaving the session.
- **Attach and swap ISOs on an existing VM.** The Disks tab now lists a VM's disc drives with Remove and Eject actions. Attach ISO is available beside Add Disk, and ISOs can be inserted into a running VM without a restart.
- **Reboot action.** A Reboot option is available in the VM details Power menu.
- **Custom VMs boot from the disk after installation.** In some cases, a custom VM re-entered its installer on every reboot. The boot order now puts the disk first so the installed operating system takes over.
- **Install media is cleaned up when you delete a VM.** Generated installation files are now removed when a VM is deleted, so leftover files no longer accumulate.
- **Bazzite installs complete reliably.** In some cases, a Bazzite VM could wait the full installation timeout without finishing. The installation pipeline now works on SELinux-enforcing guests.
- **IPv6 and multicast work on non-bridge networks.** In some cases, a VM on a macvtap NIC could not reach IPv6 addresses or local services that rely on multicast (mDNS, Home Assistant).
- **VMs cannot take hardware the server depends on.** HexOS now identifies the drives, controllers and network interfaces your server needs and keeps them off the passthrough list.

### Buddy Backup

Buddy Backup lets you back up folders from one HexOS server to another, whether it is a second server you own or a friend's server across the internet, with end-to-end encryption over a private mesh network. [Read the full announcement.](/blog/2026-09-09)

- **Interrupted backups resume automatically.** A backup run that was interrupted by a server restart now picks up where it stopped instead of staying open forever.
- **Offline buddies are held, not failed.** When your backup partner's server goes offline, the backup is placed on hold rather than marked as failed, and resumes on its own when the connection is restored.
- **Safer connection removal.** Removing a connection that holds data now requires a typed confirmation, names every stored restore point that will be deleted, and points to pause as the reversible alternative.
- **Stall detection.** A transfer whose progress counters stop moving for ten minutes is now flagged as stalled with a suggested remedy, instead of appearing to run indefinitely.
- **Clearer quota errors.** When a backup exceeds the available space, the notification now shows the exact storage needed versus what is available.
- **Hourly schedule for your own servers.** Backups between two servers you own can now run hourly for a tighter recovery window.
- **Accepted request notification.** When someone accepts your backup request, you now receive a notification on your server.
- **Improved folder picker.** The folder picker now blocks a dataset that a selected parent already covers, and touch scrolling works on Android.
