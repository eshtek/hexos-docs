# October 30, 2026 - Network UPS setup, a Valheim server, Mac drives in Bring over, and more

Here's what shipped since our [last update](/release-notes/command-deck/2026-10-28).

## Power

- **Connect a network UPS.** If your UPS has a built-in NUT server, or another computer shares one, connect it from **Settings** > **Power** > **Connect network UPS**. **Test connection** checks your details before you save, and automatic shutdown stays off until you turn it on.
- **Find network UPS** searches your network from your server and fills in the form for the UPS you pick.
- **Watch more than one UPS.** Add up to four more with **Add monitored UPS** to see each one's charge, runtime and load side by side. Automatic shutdown still follows the UPS your server is set up with.

## Bring over

- **Mac drives.** Bring over now copies from Mac-formatted (APFS) external drives. Encrypted drives and drives with more than one volume aren't supported yet.
- In some cases, a drive listed a file that couldn't be opened, such as a file with an emoji in its name on an older Mac drive. The copy now finishes and tells you which folder completed with errors, instead of reporting a clean copy.

## Dashboard

- In some cases, hardware charts filled only half of their card. They span the full width again.
- The dashboard sends fewer requests while it first loads and waits to start its repeat checks until your server's first results are in, so busier servers have less competing for the connection.

## Welcome

- In some cases, the welcome opened again in every new tab. Closing it now keeps it closed, and **Skip for now** hides it for a day. You can always reopen it from **Settings** > **First-time setup**.
- The welcome now reports only the memory test you start from it, not an older one.

## Buddy Backups

- **Hide warnings about reserved backup space.** Hosting a buddy's backup sets aside space on your pool, and that unused space could set off your pool's capacity warning before much was stored. When you approve a larger allowance, HexOS asks whether to hide warnings about the reserved space. You can change your choice anytime with **Hide capacity warnings for reserved backup space** on the hosted backup's card. Warnings about data actually stored stay on. [Learn more](/features/backups/host-a-buddys-backup#hide-a-warning-about-reserved-space).
- When a folder grows past the space your buddy reserved, HexOS now notices right away and pauses scheduled backups, rather than up to six hours later.

## Everything else

- In some cases, opening Command Deck while signed out showed an error for a moment before the sign-in page. It now goes straight to sign-in.
- In some cases, the custom install script editor lost its line numbers and colors. It displays correctly again.

## New curated apps

- [Valheim](https://www.valheimgame.com/) - Your own Valheim world, running on your server so friends can play whenever they like. They join with the code on the app's card from any platform Valheim plays across, with nothing to set up on your router. The server updates Valheim when nobody is playing and backs up your world every hour.

**NOTE:** These updates apply automatically. You may need to [clear your cache](/troubleshooting/browser-cache).
