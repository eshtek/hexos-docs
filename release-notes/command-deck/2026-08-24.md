# August 24, 2026 - Danish language support, storage improvements, and dashboard polish

Here is a summary of changes shipped since our [last update](/release-notes/command-deck/2026-08-21-2).

## Dashboard

- Long text on dashboard cards is now properly clamped with ellipses and hover titles, preventing overflow on translated strings and longer server names

## Memory testing

- Memory test time estimates now use your server's measured reboot history for a more accurate countdown

## Storage

- Pool delete confirmation now accepts the display name you gave the pool, not just the internal ZFS name
- Pool names are applied before the pool first appears on the dashboard, so you see your chosen name immediately
- In some cases, Western Digital drives with vendor-prefixed model strings were not triggering the SMR drive warning. This has been corrected.
- Resolved an issue on TrueNAS 25.04.0 where pool scrub scheduling could fail due to a legacy API serialization limitation

## File browser

- Upload notifications now name the uploaded folder and its destination for clearer context

## Danish language support

- Danish is now available as a language option in Command Deck, thanks to the work of our community translators
- Want to help bring HexOS to your language? Contribute at [translate.hexos.com](https://translate.hexos.com) and join the conversation on [Discord](https://discord.gg/fCW2htvYdz)

> **Thank you:** renesdk for pushing Danish past the 60% approved threshold and making it the first community-translated language to ship in HexOS

**NOTE:** All of these updates are applied automatically to your Command Deck. You may need to clear your cache. Help with clearing your cache is available [here](/troubleshooting/browser-cache).
