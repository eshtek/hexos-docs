# August 7, 2026 - Redesigned navigation, community translations, and stability hardening

Here is a summary of changes shipped since our [last update](/release-notes/command-deck/2026-07-16).

## Buddy Backups: Coming Soon

This release includes the full infrastructure for Buddy Backups: peer-to-peer encrypted replication between HexOS servers. The networking layer, provisioning engine, scheduling system, and restore pipeline are all shipping in this update. The feature is currently gated as we finalize testing with our internal fleet, but the groundwork is live and ready. When Buddy Backups opens up, there will be nothing to install or update: it will simply activate on your existing Command Deck. Stay tuned.

## Redesigned Navigation

- New sidebar navigation with an icon rail that collapses for more screen space
- Unified sidebar across server and account areas for consistent navigation
- Settings redesigned as a master/detail layout with distinct routes for every section
- Account management rebuilt as a tile-grid page with responsive detail panes
- Theme switcher now supports dark, light, and system (OS preference) modes
- Mobile navigation consolidated into an offcanvas sidebar with a three-dot utilities menu
- Improved mobile layout with better spacing, alignment, and touch interactions

## Community Translations (i18n)

- We need your help! Want to translate HexOS into your language? [Learn how to contribute](/community/translating-hexos) and join the conversation on [Discord](https://discord.gg/fCW2htvYdz)
- HexOS Command Deck now supports community-contributed translations via Weblate at [translate.hexos.com](https://translate.hexos.com)
- All user-facing strings are now translatable
- Languages ship to production once they reach 60% approved coverage

## Memory Testing

- One-click memory test from the dashboard Memory card: HexOS reboots your server into Memtest86+ and runs a fully unattended test with machine-verified results
- No need to walk to the server or read the screen: results are recorded automatically and displayed when the server comes back online
- HexOS detects when installed memory changes (DIMMs added, removed, or swapped) and recommends a memory test via a health warning and notification
- ECC memory detection now reported on the memory details card
- This feature is launching as a beta hidden behind our "dev mode" while it goes through final testing

## Storage & Folders

- Pool capacity updates immediately after resilver or expansion completes instead of waiting for a cache refresh
- Storage sizes now format in TB past 1,000 GB with trimmed decimals
- Unused drives now correctly appear on the pool drives page
- Hide the Replace button for drives that are not pool members
- SMB share options are now preserved when editing a folder

## Setup & Compatibility

- Motherboard name now displayed in system devices
- Private LAN addresses are now rejected in the manual WAN IP entry dialog

## Reliability

- Renaming a network interface no longer causes a brief server disconnection
- Switch to local mode is now available whenever a local access domain exists, even if the health probe lags
- Duplicate TrueNAS alert emails are now suppressed with a cooldown window
- LAN IP detection is now stable on servers with multiple network interfaces
- HexOS app updates now reach servers with intermittent connectivity
- Dashboard telemetry charts are now smoother and more responsive on longer time ranges

**NOTE:** All of these updates are applied automatically to your Command Deck.  You may need to clear your cache.  Help with clearing your cache is available [here](/troubleshooting/browser-cache).
