# November 10, 2026 - Automatic app updates, fan curves, game servers, and more

Here's what shipped since our [last update](/release-notes/command-deck/2026-11-06).

## Automatic app updates

One of our most requested features is here. HexOS can now keep your apps up to date for you.

- **Pick the apps you want updated.** Turn on **Automatic Updates** from the switch on an app's **Customize** tab, or click **Auto-Update** on your installed apps list to manage them all at once.
- **Updates run in a daily window you choose**, in your server's timezone.
- **New versions wait 7 days first.** This gives us time to catch a bad release before it reaches your server. Versions under maintenance are skipped.
- **Every update is undoable.** HexOS takes a restore point of the app before it updates.
- Automatic updates are off until you turn them on. Look for the **Want HexOS to keep your apps updated automatically?** prompt on your installed apps list.

## Fan curves for your drives

- **Cool your drives, not just your processor.** Motherboard fan settings usually only watch the processor, so drive bays can run hot during long copies or pool checks while the processor stays cool. On supported motherboards, open the **Processor** card on the dashboard and click **Fan curves**. Your fans can follow drive temperature or processor temperature.
- Choose **Quiet**, **Balanced** or **Cooling**, or build your own curve.
- **Built-in safety.** Fans never drop below 20%. If a temperature sensor stops reporting, fans run at full speed. If HexOS stops, your motherboard takes back control of the fans within seconds.

## Apps

- **Update an app that won't start.** Some apps need an update before they can start again. Nextcloud, for example, can update its own files ahead of its app version. When an app is stuck starting or has crashed, clicking **Update** now offers to fix it, with a restore point saved first. If the app still won't start, HexOS tells you and points you to a guide and **Get help**.
- **Roll back the app version, not just its data.** When you restore an app from a restore point taken before an update, HexOS can now put the earlier app version back too, as long as TrueNAS still has it. This is on by default for pre-update restore points. An app you roll back won't be updated to the same version again automatically.
- **Reset curation keeps your data.** In some cases, resetting an app's curation pointed it at new, empty folders, so a Minecraft server in Crafty Controller seemed to disappear. Reset now keeps every folder the app is using and takes a snapshot first. If an app's folders aren't the HexOS defaults, the confirmation tells you and lets you choose whether to reset them too.
- In some cases, apps that set up a database during install, like Mealie, crashed over and over when the Applications folder was shared on the network. HexOS now gives the app its own folder. If that folder already holds someone else's files, the install stops and explains what to do.
- Permission repairs now only add missing entries. Permissions you set by hand are kept.
- Nextcloud updates now take their restore point and keep Nextcloud able to read its own settings.

## App collections

- **Keep the apps you already have.** In some cases, unticking apps you already had in a collection like Media library greyed out **Continue**. Apps you already have now count toward each step, and an app you leave unticked is left completely alone.
- **Your admin logins stay yours.** Apps you tick keep their own admin accounts. When a collection needs to sign in to one, a new **Sign in to your apps** step asks you for it.
- In some cases, **Provide Input** did nothing during a collection setup because its dialog opened behind the setup window. Dialogs now open on top.
- The **Local AI** graphics card step now lists the cards you can pick first and links to a guide on which cards work.

## Storage

- **Time remaining for pool checks.** The **Checking pool** progress bar now shows about how long is left.
- **Smarter drive health.** In some cases, a single old error kept a drive marked as failing, even after it passed its tests or its cable was replaced. HexOS now looks at whether errors are still growing. You can dismiss a drive alert, and it comes back if anything gets worse.
- A drive that ZFS marks as degraded, faulted or offline now shows as **Unhealthy** and sorts first. A new card lets you know when a pool is healthy again.
- A spare drive that isn't in any pool now shows a warning instead of **Action required**.
- The pool panel now shows its layout, like **Drives: 3 (RAIDZ1)**, and usage sizes stay on one line.
- In some cases, hard drives without a model name showed up as SSDs. They now show the right icon and label.

## Locations

- **Adding a pool no longer moves your locations.**
- Media locations now have a **Use this location** switch. A Media folder you delete or turn off stays gone after updates.
- The **Create Default** button in **Locations** no longer shares the Applications and Virtual Disks folders on the network.

## Power and UPS

- **Safer UPS shutdowns.** In some cases, a UPS that reports a very high low-battery point shut the server down just minutes into an outage, with most of its runtime left. HexOS now sets a safer shutdown point for the USB UPS units it sets up.
- **Power** settings now warn you when a UPS is being monitored with automatic shutdown turned off. The dashboard **Power** tile shows **Auto shutdown off** too.
- When **Start USB monitoring** isn't available, a note above it now explains why.

## Dashboard

- **Memory shown the way RAM is sold.** In some cases, a server with 64 GB of RAM showed a total of 67.34 GB. Memory, graphics card memory and app memory now use the same units RAM is sold in. A hint explains why the total sits a little below what you installed.
- In some cases, Intel graphics cards showed a constant 100% usage on TrueNAS 25.10. Usage now reads correctly.
- **Media cards explain themselves.** When a media card's widget needs a sign-in, the card now stays open and tells you, like "Sign in to Plex to see your library here".
- Long movie titles and usernames on media cards now slide so you can read them in full. Hover over the card to pause.

## Files

- **Approve download sources.** **Download from the internet** now asks you to approve each website before your server downloads from it. You can manage approved sources in the download dialog.
- Canceling a download from the internet now stops it right away.
- Moving files between folders now holds up better if HexOS restarts partway through.

## Setup and compatibility

- **Reinstalling TrueNAS is smoother.** In some cases, after a boot drive was replaced or TrueNAS was reinstalled, setup timed out at **Waiting for connection**. HexOS now recognizes your earlier HexOS install on the imported pool and picks it up in the same setup.
- In some cases, restore points didn't work on TrueNAS 25.04.0 and 25.04.1. They now work on those versions.

## Virtual machines

- In some cases, VM setup reported success even when the installer inside the VM had crashed. When HexOS can't confirm that setup finished, it now says so and suggests checking the console.

## Remote access

- In some cases, servers using their own domain with allowed regions turned on couldn't get security certificates, and browsers showed an SSL error. Certificates now work with allowed regions.

## Privacy

- Signing out now clears your account's records from the browser, including in your other tabs.
- Download links are no longer kept in task history.

## New curated apps: game servers

Host your own game servers on HexOS. Each one gets its own folder and ports, so you can run more than one copy. Most show who's online right on their card.

- [ARK: Survival Evolved](https://store.steampowered.com/app/346110/ARK_Survival_Evolved/) - Run your own ARK server for you and your friends.
- [Factorio](https://factorio.com) - Build factories together on your own Factorio server. Your world is saved before HexOS stops the server.
- [Pelican](https://pelican.dev) - Host many game servers from one panel. Pelican Wings runs the panel's game servers.
- [Project Zomboid](https://projectzomboid.com) - Survive together on your own Project Zomboid server.
- [Pterodactyl](https://pterodactyl.io) - Host many game servers from one panel. Pterodactyl Wings runs the panel's game servers, and HexOS keeps its game ports free for it.
- [Satisfactory](https://www.satisfactorygame.com) - Run your own Satisfactory dedicated server.
- [Terraria](https://terraria.org) - Run your own Terraria server. Your world is saved before HexOS stops the server.
- [TShock](https://github.com/Pryaxis/TShock) - A Terraria server with admin tools. Its admin setup code is on the app's **Settings** tab.
- [tModLoader](https://www.tmodloader.net) - Run a modded Terraria server, with a web dashboard to manage it.
- Palworld's card now shows who's online too.

**NOTE:** These updates apply automatically. You may need to [clear your cache](/troubleshooting/browser-cache).
