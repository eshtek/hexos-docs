# August 20, 2026 - File browser upgrades, instant app details, and reliability improvements

Here is a summary of changes shipped since our [last update](/release-notes/command-deck/2026-08-17).

## File browser upgrades

- Upload entire folders from your computer, with nested subfolders preserved
- Add more files to an active upload without waiting for it to finish
- Navigate files with arrow keys, matching the Finder and Explorer experience you are used to

## Apps

- App details now open instantly from the catalog, with no loading delay

## Reliability

- In some cases, a TrueNAS API key could become invalid after a system change. Command Deck now detects this and automatically reconnects with a fresh key, so your server stays online without manual intervention.
- We identified a scenario where setup wizard provisioning steps could appear out of order. Steps now always display in the correct sequence.

**NOTE:** All of these updates are applied automatically to your Command Deck. You may need to clear your cache. Help with clearing your cache is available [here](/troubleshooting/browser-cache).
