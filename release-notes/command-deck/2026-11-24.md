# November 24, 2026 - Buddy Backups and VMs out of beta, encrypted Bring over, clearer app errors, and more

Here's what shipped since our [last update](/release-notes/command-deck/2026-11-20).

## Buddy Backups and virtual machines are out of beta

Buddy Backups, virtual machines and VM setup steps no longer carry a **Beta** badge. Thank you to everyone who tried them early and told us what to fix.

- **Bulk actions you can trust.** When you select several backups on the **Backups** page, every action now applies to exactly the servers, pools, speeds and schedules you reviewed. A dialog stays open until its changes have finished saving.
- On TrueNAS 25.04.0 and 25.04.1, which have no virtual machine support, VM actions and graphics card sharing now tell you to update TrueNAS instead of failing partway. A **System Wipe** on those versions now stops before it changes anything.
- In some cases, apps that HexOS stopped to share a graphics card didn't start again after a server restart. They now come back once TrueNAS lists its apps again.

## Global search
- **Easy access** There is now a new global search bar that you can always access, no matter  where you are in the application.
- **Search everything** Quickly find folders, apps, settings, and more.
- **For power users** Use Ctrl + K or Cmd + K on your keyboard to open up the search interface with an intuitive shortcut

## Bring over

- **Encrypt new folders as you bring them over.** The **Review** step now offers **Encrypt new folders**, so the folders Bring over creates are encrypted from the start with HexOS-managed keys. There's no need to copy your files first and convert the folders afterward.
- **Easier choices on the Location step.** Each folder now has two buttons, **Everyday** and **Media**, instead of a narrow dropdown that cut off its options. HexOS's suggestion shows under the buttons.
- **Unraid sources with a stopped array.** In some cases, starting the array in Unraid and clicking **Check again** didn't unlock the shares. Bring over now reads the source again, so you can pick your folders without signing in again.
- When a scan finishes, the devices it found are now sorted by type and name.
- When you're signed in with TrueNAS and choose a cloud source that needs a HexOS account, Bring over now offers to sign you in with HexOS. It brings you back to the same server and source afterward.

## Apps

- **Know why an update failed.** When an app update failed, HexOS would show TrueNAS's raw error and a log path. Now it says what went wrong in plain words, like another app using the same port, and what to do next. Update notices name the versions involved. Once the app runs at its new version, the failed notice clears by itself.
- **Start an app that got stuck.** In some cases, when an app's start failed, for example because a folder it uses was locked, the app stayed on **Starting** with only **Uninstall** left to click. Its **Start** button now works again. If a start is refused, the message says why, like which folder is locked.
- **Your folders stay safe.** In some cases, **Start clean** or uninstalling an app with its data could include a folder that another installed app still used. HexOS now keeps every folder another app can still reach.
- **Slow first starts finish.** In some cases, apps with a slow first start, like Automatic Ripping Machine on hard drives, failed their install or a setup step while TrueNAS was still starting them. HexOS now waits for as long as the step allows.
- Automatic Ripping Machine now shows its own tile in the app catalog.

## HexOS Anywhere

- **A domain for each server.** If you bring your own domain and have more than one server, each server now gets its own domain on the **Custom domain** tab, with its own DNS record. App names only need to be unique on their own server.
- If your servers shared one domain before, the server with the most addresses on it keeps it. Your other servers go back to their HexOS addresses until you give each of them a domain of its own. Nothing is deleted.

## Setup and compatibility

- **Memory tests finish on more computers.** In some cases, on computers like the Dell OptiPlex, the memory test kept running for days until someone pressed a key at the server, and no result was saved. The memory test now stops after its passes and reports its result.
- **Network changes you test in TrueNAS stay yours to confirm.** In some cases, when you tested a network change in TrueNAS with **Test changes**, a HexOS restart or update would confirm it for you. If the change cut your server off the network, TrueNAS couldn't undo it. HexOS now only confirms the network changes it makes itself.
- Downloaded files with apostrophes or parentheses in their names now keep their names.

## Privacy and security

- When you sign out of your HexOS account, the list of servers remembered for offline use is now cleared from the browser. On a shared computer, the next person can't see your server names or addresses.
- The offline page now works for servers with IPv6 addresses or a missing name.
- HexOS sign-in and account recovery pages no longer load any tracking.
- We tightened security checks across HexOS Anywhere, the connection between your servers, sign-in and the software packages HexOS runs on.

**NOTE:** These updates apply automatically. You may need to [clear your cache](/troubleshooting/browser-cache).
