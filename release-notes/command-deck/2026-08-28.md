# August 28, 2026 - Dashboard widgets, install scripts v6, cross-app linking, and storage polish

Here is a summary of changes shipped since our [last update](/release-notes/command-deck/2026-08-27).

## Storage

- Pool cards now show a hover readout of used and free space on the capacity ring
- In some cases, Western Digital drives connected via USB bridges were not triggering the SMR drive warning. This has been corrected.
- Empty states for apps, backups, and storage now use consistent pool-card-sized placeholders

## Folders

- The "restore folders" notice now only appears for pools that were actually imported during setup, not for pools that were kept and already have their shares intact

## Setup

- When private access mode has no local users, HexOS now offers to create one instead of showing an empty state

## Dashboard widgets

- Curated apps can now place live widgets directly on your dashboard, showing real-time information from your running apps without opening them
- This is the backend infrastructure for widgets. You will see apps taking advantage of this soon.

## Install scripts v6

This release ships the backend for install scripts version 6, a significant upgrade to how curated apps are configured and connected. V6 merges lifecycle hooks, user-triggered actions, and widget declarations into a single unified schema. This means:

- Apps can now offer hooks you can run on demand from the app's options, not just during install
- Cross-app linking lets one app's install connect it to another app automatically (for example, installing Seerr can install and connect Jellyfin in the same flow)
- Completed hook actions now show detailed checkpoint history in notifications instead of a generic one-liner

You will see curated apps taking advantage of these capabilities soon. For more on how install scripts work, see the [install scripts documentation](/features/apps/install-scripts/overview).

**NOTE:** All of these updates are applied automatically to your Command Deck. You may need to clear your cache. Help with clearing your cache is available [here](/troubleshooting/browser-cache).
