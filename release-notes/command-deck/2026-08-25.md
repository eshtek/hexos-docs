# August 25, 2026 - HexOS Imager API, smarter uploads, and storage safety improvements

Here is a summary of changes shipped since our [last update](/release-notes/command-deck/2026-08-21).

## Introducing HexOS Imager

Installing HexOS on your server should not require hunting for ISOs or figuring out third-party tools like Balena Etcher or Rufus. We are building HexOS Imager: a single, purpose-built tool that downloads the latest HexOS installer and writes it to a USB drive for you. This update ships the public API that powers it, delivering available releases directly to the Imager so it always has the latest version ready. HexOS Imager is coming soon.

## File browser

- Upload progress is now weighted by file size, so a folder with one large file and several small ones reports an accurate percentage instead of jumping ahead
- Upload notifications now show the destination folder name instead of the last file that completed
- Folder uploads display the folder name in the activity card for clearer context

## Apps

- App update cards now display current and available versions in a stacked layout, making it easier to see what is changing before you update

## Storage

- USB drives are now excluded from pool expansion candidates for non-USB pools, preventing accidental additions that could compromise your storage

## Reliability

- In some cases, servers could become temporarily unreachable due to a stale network connection that was not cleaned up. Command Deck now detects and tears down these connections automatically.
- Self-update delivery has been improved for servers with intermittent connectivity

**NOTE:** All of these updates are applied automatically to your Command Deck. You may need to clear your cache. Help with clearing your cache is available [here](/troubleshooting/browser-cache).
