# Common issues

Choose the guide that matches your problem. The [Troubleshooting page](/troubleshooting) has the full list.

- [**Application errors**](/troubleshooting/apps) - Find help with app installation, updates and startup.
- [**USB drives for storage**](/troubleshooting/usb-drives) - Learn why USB connections can cause storage problems.
- [**Clear browser cache**](/troubleshooting/browser-cache) - Clear old browser data when the interface does not load correctly.
- [**Drive failure**](/troubleshooting/drive-failure) - Check a failed drive and follow the replacement steps.
- [**Move to new hardware**](/troubleshooting/migrating/new-hardware) - Move an existing installation to another server.
- [**Update TrueNAS 24 to 25**](/troubleshooting/migrating/truenas-24-to-25) - Follow the upgrade guide for an older installation.
- [**Immich and Postgres 18**](/troubleshooting/migrating/immich-postgres-18) - Follow the database upgrade guide for Immich.
- [**Windows 11 file sharing**](/troubleshooting/file-sharing) - Find help when Windows cannot connect to a public folder.

> **Help:** If no guide matches, ask in the [HexOS Discord Community](https://discord.gg/fCW2htvYdz). Describe your problem before changing storage or deleting anything.
