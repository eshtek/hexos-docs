# Immich storage migration

The earlier instructions have been retired. Use [Update an older Immich storage layout](/troubleshooting/migrating/immich-storage) if your app has **Use Old Storage Configuration (Deprecated)** and separate **Host Path** folders.

The replacement keeps the database separate, checks copied media and preserves the original folders. Read its requirements before changing anything.

For a different layout or a move to another pool, contact [HexOS support](mailto:support@hexos.com) with your installed app and catalog versions. Keep the existing files and database intact. Do not send passwords or personal photographs.
